# 🍞 Bakery Stock Management System

A full-stack **Bakery Stock Management System** designed to manage bakery inventory, purchases, damages, transfers, and reports efficiently.  
The system includes a **React.js frontend**, **Node.js + Express backend**, and **MySQL database**, with role-based access and dashboard analytics.

---

## 📌 Features

### 🔐 Authentication
- User login with JWT authentication
- Secure password hashing using bcrypt

### 📦 Stock Management
- Bakery stock tracking
- Cutlery asset management
- Purchases, damages, and transfers
- Real-time stock updates

### 📊 Reports & Dashboard
- Stock reports
- Cutlery stock reports
- Visual charts using Chart.js
- Centralized admin dashboard

### 📁 File Handling
- File uploads using Multer
- Export reports using XLSX

---

## 🛠️ Tech Stack

### Frontend (Client)
- React.js
- React Router DOM
- Axios
- Chart.js
- Font Awesome / React Icons
- Swiper
- XLSX

### Backend (Server)
- Node.js
- Express.js
- MySQL
- JWT Authentication
- Multer (file uploads)
- bcrypt (password hashing)

### Database
- MySQL  
- SQL schema provided (`bakery system db.sql`)
